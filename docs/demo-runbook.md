# Yardmaster sandbox demo

This repository is a safe target for demonstrating Yardmaster's pull request queue.

## Demo flow

1. Open the Yardmaster dashboard.
2. Select `yardmaster-sandbox`.
3. Queue one or more ready pull requests.
4. Observe FIFO ordering and status changes.
5. Remove completed demo entries when the walkthrough ends.

## Reset

Close any remaining demo pull requests and delete their `demo/*` branches.
